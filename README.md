# AI Troubleshooter

A small Python project created to learn the basics of building an **AI agent**.

The project explores how an AI model can receive a user request, use tools, and return a response based on the available information.

## Technologies

* Python
* OpenAI API
* AI Agents
* Python functions / tools

## Project Structure

```text
ai_troubleshooter/
├── ai_agent_learning/
├── agent.py
├── config.py
└── tools1.py
```

## Purpose

This is primarily a learning project for experimenting with:

* AI agents
* Tool calling
* Python functions as tools
* Sending requests to an AI model
* Basic agent logic

## Status

Learning project — kept intentionally simple while experimenting with AI agent concepts.
